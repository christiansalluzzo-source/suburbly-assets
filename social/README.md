# Suburbly social: instructions for Muse

Start with **MUSE_BRIEF.md** (who we are, voice, plan facts, hard rules, posting plan), then:

- **CAPTIONS.txt**: every file in the Google Drive pack, what it shows, ready captions
- **LINKS_AND_HASHTAGS.txt**: tracked links for every post, account links, hashtags
- **REPLIES.txt**: ready answers for comments and DMs

The images and videos are in the Google Drive folder `Suburbly_Social_Pack` (same file names as in CAPTIONS.txt). If this folder and the Drive copy ever differ, this folder is the newer one.
