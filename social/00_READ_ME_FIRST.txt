SUBURBLY SOCIAL PACK — READ ME FIRST (2026-10-23)

This folder is everything Muse needs to post Suburbly on social media (organic posts, not ads)
on Facebook, Instagram, X, YouTube and TikTok. Platform rules: BRIEF.txt section 7b.

Read in this order:
  1. BRIEF.txt              who we are, who we talk to, voice, plan facts, HARD RULES, posting plan
  2. CAPTIONS.txt           every file in this pack, what it shows, ready captions (A/B)
  3. LINKS_AND_HASHTAGS.txt tracked links for every post, account links, hashtags
  4. REPLIES.txt            ready answers for comments and DMs

The same instructions live in GitHub (newest version wins):
  https://github.com/christiansalluzzo-source/suburbly-assets/tree/main/social

File codes (start of each file name, use them in utm_campaign):
  R = Reel 9:16   F = feed video 4:5   L = landscape video 16:9
  P = single image   C = carousel   T = trade image pair   S = app screen for Stories

First post: R1 (01_reels_9x16_with_music/R1_overview_every_house_on_one_map.mp4)
on all five platforms; pin it on Facebook, Instagram and X.

If something isn't covered here: don't guess, leave it out and flag it.
